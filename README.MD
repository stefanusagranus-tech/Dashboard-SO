# 📊 Dashboard Stock Opname

Dashboard monitoring progres Stock Opname (SO) per rak untuk **Toko C383 - Karang Satria**.

## 🎯 Fitur Utama

- ✅ Monitoring **% progres SO** dari 144 rak
- ✅ Deteksi **rak belum SO** (visual highlight)
- ✅ Hitung **BTSB** = 0,15% × Net Sales
- ✅ Hitung **selisih & nominal adjustment**
- ✅ Generate **briefing otomatis** untuk item minus terbesar
- ✅ Chart & diagram interaktif
- ✅ Rekap **PIC per rak**
- ✅ Export ke **Google Spreadsheet**

# Clone repo
